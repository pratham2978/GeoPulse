# GeoPulse AI — Global Conflict Impact Intelligence Platform

GeoPulse AI is a futuristic, cinematic web platform that analyzes global conflicts, economic signals, energy markets, trade routes, and public sentiment to measure how geopolitical events impact the world.

## 🌐 Features

- **Live Reconnaissance Globe**: Cinematic 3D space visual with pulsing conflict hotspots (Red Sea, Strait of Hormuz, Strait of Malacca, Black Sea Grain Corridor).
- **Interactive Cyber Decryption**: Military/defense-grade cryptographic scramble and letter decoding text animations.
- **Dynamic Kinetic Keywords**: Real-time rotating geopolitical focal points with cyber decryption waves.
- **Holographic Aurora Shimmer**: Multi-stage iridescent lightbeam sweep across primary headlines.
- **Real-time Satellite Telemetry Ticker**: Continuous scrolling live data marquee displaying maritime AIS congestion, commodity spreads, chokepoint escalation indices, and sentiment metrics.
- **Floating Intelligence Telemetry**: Glassmorphic cards tracking energy volatility, maritime transit delays, active signals, and narrative polarization.
- **End-to-End Pipeline Visualization**: 5-stage intelligence flow from global signals to actionable scenario models.

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS**
- **Lucide React**
- **Helvetica Now Var Typography**

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
